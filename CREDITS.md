# Créditos

## Bibliotecas

| Biblioteca | Versión | Licencia | Uso |
|---|---|---|---|
| [raylib](https://www.raylib.com/) | 5.5 (C) | zlib | ventana, texturas, audio, input |
| [raylib-rs](https://github.com/deltaphc/raylib-rs) | 6.0 | zlib | bindings Rust para raylib |
| [image](https://github.com/image-rs/image) | 0.25 | MIT/Apache-2.0 | carga de PNG con canal alfa |

## Algoritmo

Implementación de DDA (Digital Differential Analyzer) para raycasting basada en el tutorial de
Lode Vandevenne: https://lodev.org/cgtutor/raycasting.html

## Recursos de arte y audio

Los archivos en `assets/` no forman parte de este repositorio. Cada usuario debe proveer sus
propios recursos bajo las licencias correspondientes. Ver README.md para la lista de archivos
necesarios.

`bgm.ogg` queda excluido del repositorio por posibles derechos de autor; colócalo manualmente
en `assets/audio/` si deseas música de fondo.
